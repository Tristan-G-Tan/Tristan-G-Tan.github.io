Memories

Summary

Dual-Track memory: Explicit=Declarative=Effortful=Conscious; Implicit=Nondeclarative=Automatic=Unconscious.

Working=short-term, just a newer understanding of it. Iconic=visual, echoic=auditory.

explicit/implicit/prospective2.3.A.1 Memories for learned knowledge, events, and experiences are differentiated by how they are processed by, stored in, and retrieved by the brain.
Explicit memory2.3.A.1.i more easily described or explained to others
episodic memory events (time & place), personal experiences
semantic memory language, facts, general knowledge
Implicit memory2.3.A.1.ii more challenging to describe or explain to others
procedural memory for procedures and processes; motor skills, muscle memory (throwing a ball), operant conditioning, classical conditioning, conditioned/unconditioned/primed responses
Prospective memory2.3.A.1.iii related to future actions
working memory model2.3.A.3 examines how our primary memory system—working memory—engages in a dynamic interaction with
central executive boss of working memory: controls our attention (should incoming information go into the phonological loop or the visuospatial sketchpad?), integrates new information with existing long-term memory
phonological loop verbal input: for spoken and written material, repeats it again and again
visuospatial sketchpad visual input: for navigation, stores and processes information in a visual or spatial form
multi-store model2.3.A.4 focuses on the impact of automatic and effortful processing on memory encoding, storage, and retrieval. Information must pass through three interacting systems to be remembered:
sensory memory immediate, very brief recording of sensory information
iconic memory for visual inputs, decays quickly
echoic memory for auditory inputs, decays slightly less quickly
short-term memory lasts 15-30 seconds if you paid attention to sensory information, holds 7 ± 2 (the magic number) items
long-term memory encoded from short-term memory (see2.3.A.3and2.4), can be retrieved later
levels of processing model2.3.A.5 proposes that memory is encoded on three levels from shallowest to deepest:
structural memory encoded from the basic visual/physical qualities of the word/concept, e.g. "baker" has 5 letters, maintenance rehearsal.
phonemic memory encoded from the basic auditory qualities of the word/concept, e.g. "baker" rhymes with "shaker".
semantic memory encoded from the meaning of the word/concept, e.g. a baker makes cakes, cookies, and pastries.
